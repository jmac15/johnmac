Changelog

This is EDU HTML5 template version 4.3

Template changes v4.3

The main changes are listed below (in no particular order):

  • Information modal - the information modal has been edited and standardized.
  • Tabs - tabs have been re-styled to look more like traditional tabs (and checked for printing and accessibility).
    Reminder: the code for creating tabs and vertical tabs has changed slightly - tabs are created using dl and dd's, and the divs containing the tabs headings are in separate divs, so they won't render beside the associated content for printing, follow the info below to create tabs that will print correctly.
    • .show-for-print needs to be added to all .content divs in tabs, (they are set to hidden in the web version).
    • .dl (tab heading) needs .hide-for-print class.
    • Duplicate titles need to be added in the .content divs, with a .print-only class
    • Another thing to remember is that we are still on Foundation 5, if you are looking at the reference docs online!

Template changes v4.2

The main changes are listed below (in no particular order):

  • Accessibility - added a doctype language (english).
  • Accessibility - added a bit of jQuery to inject an alt tag into the background image.
  • Accessibility - added text beside the back and next buttons that can only be seen by screenreaders, to describe the link and help assistive technologies navigate (a text equivalent of an element can be either inside or around the element).
  • Accessibility - to hide text from assistive technology, while still keeping it visible, add the attribute aria-hidden="true". This doesn't affect how the element looks, but screen readers will skip over it.
  • Accessibility - added :focus to all :hover links, so that the hover states also show when using keyboard navigation (eg. tabbing to the next link on the page).
  • Accessibility - you can also now use .show-for-sr to show for screenreader, hide else.
  • PDF's and printing - section added to the info key.
  • Useful classes - Visible for printing - .show-for-print , .print-only
  • Useful classes - Hidden while printing - .hide-for-print , .hide-on-print
  • Using modal windows - Content that’s inside modal windows, tooltips and dropdowns needs to be inside the main article tag and given a class .show-for-print, otherwise it won’t print.
  • Tabs and accordions - need the class .show-for-print in the content div.
  • Horizontal and vertical tabs - need .hide-for-print added to the dl tag that holds all the tab headings, as they won’t print beside the relevant content
  • Pre-defined classes page - more information about built-in classes in the Pre-defined classes page of the template documentation
  • buttons - edited CSS so that mobile button colours were also controlled by main.css.
  • Header text - edited header text sizes.
  • Book case - new code that makes the link target area as big as possible, whilst adding back in the 'more info' functionality for book descriptions. Added hover state drop shadow rollover. CSS optimised. Book case added to main template, and also documentation folder, where there is also some explanitory text. CSS pulling in from the same place, in main template css folder.
  • Navigation - Navigation styles added to main.css so they can be quickly edited with the rest of the theme colouring. Current classes also added to main.css (with media queries) so they can be added in the same place.
  • Mobile nav button - position of button (when activated) changed to jump to right of nav, as opposed to far right of screen (closer for better usability). Topic title and other buttons also toggles when nav activated, to give more space and cleaner appearance for mobiles.
  • Alert boxes - font sizes larger, to be same as the rest of the text.
  • Interface elements - page edited so displays better on mobile devices.
  • Font awesome icons - arrows updated to most recent code. Activity icon CSS edited for mobiles.
  • List items - padding edited so that they look better on mobiles.
  • Version added to title page - devs can check what version of the template they are using by checking the title page and in main.css.
  • Pages now printable - edited CSS so that pages can now be directly printed from the browser (and look good!)
  • Navigation menu (asset file) - page class now on list item (as opposed to a tag). Title attributes removes - more harm than good for screen readers.
  • responsive images - auto centre all responsive images, so that they sit in the middle when the page is linearlized.
  • Accordions - margin added to bottom to even out page spacing.
  • Plugins.js - jquery added to plugins file that can be used as a multiple slide hover interaction (good for responsive image maps).
  • Inline icons - Pdf icon added. Home icon replaced (with new Font Awesome code).

Template v3 changes

Template version 3 had had many changes to the code since the last release, the best way is to put a wee bit of time aside and go in and look about it, the main points are included below.

  • General - The HTML and CSS have been edited and optimised to remove anything that could be removed.
  • Navigation code - Quicker implementation of navigation using JavaScript code, which will auto hide sub-nav items on sections the user is not looking at. More info on devs blog here.
  • Spacing - margin, padding and guttering - has been refined. Padding on all p tags inside panels and tabs, but it is set to remove padding from the last child element (so that the padding at the bottom doesn't combine with it to make it too big).
  • Foundation - Many changes to Foundation Framework. More info here.
  • Foundation - Styles that over ride the Foundation.css styles have been put into main.css (for easier updating of Foundation in the future).
  • Creating themes - Most colouring styles needed to create a new theme are in a section of the main.css, so that it's quick and easy to edit.
  • Plugins.js -re-usable code - Popular re-usable code has been added into plugins.js - for speed of download and also implementation. More info here.
  • Lightbox - Added lightbox2 to plugins.js and main.css so you don't need to call the script on pages you want to use it.
  • Modernizr - script has been added back in, as some features were not working without it. More info here.
  • Interactions removed - Interactions have been removed from the template, and will be put in our Portfolio of Interactions.
  • Fittext.js - has been removed, and CSS used as an alternative.
  • Icons - have been edited, and CSS has been optimised.
  • Bookstand - has been edited
  • Modal - code must be in the div that the trigger is called now (the article tag)
  • jQuery UI - 'slide in' code added (a slimmed down version of jQuery UI has been downloaded, so only the 'slide in' function will work). Add css/jquery-ui-slide.min.css and js/jquery-ui-slide.min.js to bottom of page you wish to use it on, and then class=slide-right-grad to element you wish to slide in.
  • Responsive tables - JS added to plugins.js for easy responsive tables - simply add class 'responsive' to tables to initiate.
