Pre-defined classes

Responsive Images

Class '.responsive-image img' has been added to 'main' stylesheet (affects all viewport sizes). To use, put 'responsive-image' class round any image and it will resize responsively. FYI: the max image size that can fit onscreen is 1000px, this is the biggest the 'article' area will allow when stretched at full width (with nav bar). So if you have a two-column layout, I suggest using an image that is 500px wide etc.

Code used to make images responsive:

In order to make images responsive, set the following declarations in css:
.containing-element img{
width:100%;
max-width:100%;
height:auto;}

Copyright

'.copyright' class to 'main' stylesheet (so shows accross all device widths). Class can be used in p tags underneath images. Puts 5px top and bottom padding, font size 75% of that specified for current device width and text aligned centre:

.copyright{
margin:0;
padding:5px 0 5px 0;
font-size:75%;
text-align:center;}

Random (self-explanitory) classes!

  • 'copyright-footer' class (in mobile, tablet and desktop css files) - for use in beside the editable area beside pagination. This is for the copyright information of current page BG image (if an image BG is used).
  • 'border' class (in main.css) - use this class on any image to give it a border
  • 'bold' class (in main.css) - give any text a span class of bold to give inline styling
  • 'padding-bottom' class (in all stylesheets) - self explanitory! Uses standard grid gutter sizes that have already been implemented. For example, this might be used on an image element at the bottom of the page to create a gutter at the bottom, the same as is set on all the other sides, but if the bottom element is in a 'p' tag, there is already padding set in the css, so it's not needed. Example on image on dev spec homepage.
  • 'no-padding' class (in all stylesheets) - also self-explanitory!
  • 'no-padding-bottom' class (in all stylesheets) - this is useful for taking the padding off the bottom of ul and ol's when they are inside panels, at the end.
  • styling for word definitions - 'class="definition"' on word you want to give definition, and 'class="panel radius key"' can be used to show the user what the green styling means. Also brings key logo into panel. (Example on 'Icons' page of dev spec). More information in the Icons & panels page
