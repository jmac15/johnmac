Interchange

Interchange uses media queries to dynamically load responsive content that is appropriate for different users' browsers.

Interchange code (new for Foundation 5)

Interchange can now pull in HTML partials so you can load different sections of your page for particular media queries. This is great for loading up a mobile-friendly component on small devices, and a more robust or heavier load component on desktops. See documentation here.

The code below will probably be wrapped in a div

data-interchange="[../examples/interchange/default.html, (small)], 
                    [../examples/interchange/medium.html, (medium)], 
                    [../examples/interchange/large.html, (large)]">

Lightning with dramatic clouds / shutterstock

Interchange image

Functionality: Floats images left or right in side a container, with javascript functionality that swaps the image, depending on screen size of device. Also used with generic 'copyright' class for caption below.

  • A 'small' (150px) image will be used for devices up to 768px wide
  • A 'large' (300px) image for anything above this (resize this page in your browser to see how the layout changes)

There are styles in mobile, tablet and desktop stylesheets for the 3 floated divs - with different margins for the 3 sizes (based on typical gutter sizes for that device) and specifying the width. You can simply change css to change the image sizes (please note: the tablet and desktop sizes are currently the same).

Classes in css: img-float-left and img-float-right

HTML

<div class="img-float-right">

<img data-interchange="
[img/thunderstorm/small.jpg, (only screen and (max-width: 767px))],
[img/thunderstorm/large.jpg, (only screen and (min-width: 768px))]"
src="img/thunderstorm/small.jpg"
alt="here is your alt tag text"
title="here is your title tag text">

<p class="copyright">Lightning with dramatic clouds / <a href="http://www.shutterstock.com/pic.mhtml?id=175229378&src=id" title="Lightning with dramatic clouds" target="_blank">shutterstock</a></p>

</div>

Styles already in stylesheets:

mobile
.img-float-left { width:150px; margin:0 7px 5px 0; float:left;}
.img-float-right { width:150px; margin:0 0 5px 7px; float:right;}

tablet
.img-float-left { width:300px; margin:0 15px 10px 0; float:left;}
.img-float-right { width:300px; margin:0 0 10px 15px; float:right;}

desktop
.img-float-left { width:300px; margin:0 20px 10px 0; float:left;}
.img-float-right { width:300px; margin:0 0 10px 20px; float:right;}
